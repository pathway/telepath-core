# Predict


```
./telepath predict \
     --project_spec=telepath_settings.yaml \
     --in_features_path=replay.csv \
     --in_spec=replay_spec.yaml    \
     --agent_path=_batch.agent_telepath \
     --out_pred_path=_predict.csv
```

## Options


### --explain

Show explanations of policy at varying levels of detail.  Note this is based purely on the prediction dataset, so for a good explanation you should use good sized input data


### --include_obs

Include observations in the output file.  This makes it a bit easier to relate actions to the observations.

### --include_q
Include Q values in the output file.  This helps debug the agent and produces summaries and charts like this:
