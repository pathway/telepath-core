## Training

Training speed depends on a number of factors including:

- dataset size
- algo_spec parameters
- inherent complexity of the problem

For this reason there is no hard and fast rule about training times.  Expect between 30 mins to days.

## Prediction

Prediction performance is much more "predictable" than training. 

1M predictions took between 16 and 23 minutes, depending on predict settings.
- measured on Nov 29, 2020
- Ubuntu 18.04, AMD Ryzen Threadripper 2950X 16-Core 64GB RAM, 
- GeForce GTX 1070 8GB GPURAM CUDA 11.0
